All advantages

Everything NotesPro brings to your team — writing, planning, menus, music, games, files, messaging, and two-factor login.

Workspaces

Multi-workspace teams

Separate projects with members, roles, and email invites so the right people see the right notes.

Structure

Folders & page tree

jsTree navigation with search, drag-and-drop reorder, inline rename, last-page memory, and restore after a soft delete.

Writing

Markdown + live preview

EasyMDE with split edit/preview, synced scrolling, floating TOC, find/replace, snippets, indent, colors, and font size.

Page

Contents & tags

Page settings can show or hide the table of contents and the tag bar. Add or remove {tag: name} markers from the same dialog.

Sheets & charts

Embedded spreadsheets

Tab-separated sheet blocks with formulas, inline markdown in cells, linked D3 charts, and images in cells — docs that calculate.

Planning

Calendar, Gantt, Kanban

Date ranges, timelines, and drag-and-drop boards directly inside markdown — no separate tools.

Time & cost

Kanban Gantt

Start / Suspend / Stop timers, Suspended column, hourly rates, optional cost totals, and wrap layout on small screens.

Ideas

Mindmap blocks

Indented idea trees in markdown for brainstorms that stay with the page.

Menu

Menu card

Each table is a panel. Use settings to set the number of tables, click dishes to order, then send a bill — archived with date and time.

Shop

SW Shop & e-shop

Software downloads plus a product catalog. Pay with PayPal, Visa, or Mastercard. Additional info sits on the shop. Card numbers are never stored.

Ads

NotesList

Local ads in markdown: categories, search, posting view, Reply to all group members, Add item by mail, and Edit for page owners.

Calcs

Engineering calculator

Octave-style calcs blocks: real and complex math, matrices, ranges, and multi-curve plots next to the source.

Python

In-browser sandbox

Run Python in a Pyodide sandbox — print, pandas, and matplotlib plots appear in the preview.

Voice

Record & transcribe

Record in the browser and transcribe locally with open-source Whisper — no cloud speech API.

Jukebox

MP3 cabinet player

Play albums in a diner jukebox: drop folders, add Google Drive, keep playing in the background, and skip random 30 / 60 / 90 second clips. Titles show folder and filename.

News

RSS feeds

Embed live news feeds in a page — Magpie-style cards from BBC and other RSS sources.

Games

Play in preview

Sudoku, chess, Tetris, Sokoban, Pac-Man, pinball, and more — interactive blocks inside the note.

Photos

3D galleries & rides

Walk-in photo corridors, cubes, books, 3D carousels, roller coaster, scooter, ghost train, and labyrinth walls from your images.

Panels

Colored callouts

Info, success, warning, danger, and note panels for structured documentation.

Quick notes

Keep view

Sticky notes with pin, colors, checklists, archive, markdown rendering, and drag reorder.

Files

Upload & media

Drag-and-drop file manager; images open in a new tab; local file links for desktop workflows.

Chat

Private & group

One-to-one messages, a workspace group channel, and optional direct connection when both people are online.

Mail

Workspace mail

Inbox, sent, and compose inside the dashboard — plus NotesPro routing for incoming mail.

Account

Two-factor login

Optional TOTP two-factor sign-in so you can protect your NotesPro account with an authenticator app.

Tags

Indexed tags

Brace tags like {tag: WLAN} with workspace search. Page settings lists them and can hide the tag bar without deleting the markers.

Issues

Workspace tracker

Numbered issues in the sidebar with status, priority, assignee, labels, and an optional related page.

Layout

Resizable panels

Sidebar, editor, and chat widths remember your layout — desktop and mobile friendly.

Import / export

Portable workspaces

Export and import workspaces so documentation and structure move with your team.
